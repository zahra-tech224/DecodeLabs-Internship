# 🤖 Rule-Based AI Chatbot

## 📌 Project Description

This is my first Artificial Intelligence internship project at DecodeLabs.

The Rule-Based AI Chatbot is a simple chatbot developed using Python. It interacts with users and provides predefined responses based on their input using if-elif-else conditional statements.

The chatbot can answer basic questions, tell jokes, provide information about Artificial Intelligence, and respond to greetings.

## ✨ Key Features

- Responds to greetings like Hello, Hi, and Hey.
- Answers basic questions about Artificial Intelligence.
- Answers questions like "Who created you?"
- Tells programming-related jokes.
- Provides information about Python and coding.
- Handles unknown user inputs.
- Supports exit commands like Bye, Exit, and Quit.
- Uses a continuous loop for interaction.

## 🛠️ Technologies Used

- Python 3
- Conditional Statements (if, elif, else)
- While Loop
- User Input and Output
- String Methods (lower and strip)

## ▶️ How to Run the Project

**Step 1:** Install Python on your computer.

**Step 2:** Download or clone this project.

**Step 3:** Open the project folder in VS Code.

**Step 4:** Open the terminal and run:

```bash
python chatbot.py
```

**Step 5:** Start chatting with the bot!

Type `bye` or `exit` to stop the chatbot.
